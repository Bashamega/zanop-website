About Zanop Technologies

An operating system that was supposed to be a joke, and then wasn't.

Where it started

John Adman started Zanop Technologies in 2022. The OS began as a fictional project made for fun, complete with imaginary products like the Zanop A Series phone, a design loosely modelled on Samsung's A Series. The idea eventually stopped being fiction and turned into working code.

The Zanop Kernel

Every Zanop product sits on the Zanop Kernel, written from scratch in Rust with some low-level Assembly, targeting x86_64. It was never written for one device. The same kernel is meant to carry several operating systems.
Variants

What the kernel runs

Variant What it is
Zanop Desktop OS Desktop build; applications are packaged as .sft files
Zanop Mobile OS Build aimed at phones
Zanop Television OS Build for televisions and set-top boxes

How we approach it

A system should be built deliberately rather than stitched together from another project's components. Zanop OS is not a Linux distribution. It runs its own kernel, written line by line by people who wanted to find out whether they could write one.
